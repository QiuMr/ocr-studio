## #75 界面精修：圆角 / 按钮尺寸 / 字号统一

### 问题（审计结果）
全站 `*.tsx` 里圆角混着 **7 个自定义像素值**（9/10/11/12/13/14/16px）+ Tailwind 默认的
sm/md/lg/xl，同一个「卡片」在不同页面圆角都不一样；字号混着 **4 个半像素值**
（10.5/11.5/12.5/13.5px）+ 10/11/12/13/14/15/16/26/27，共 13 档。半像素值在 100%
缩放下发虚，差 0.5px 的两档放一起既看不出差别又显得不整齐。

### 做法：覆盖 Tailwind 默认档，而不是逐处改
`src/styles.css` 的 `@theme` 里直接覆盖 `--radius-*` 与 `--text-xs/sm`，
这样既有的 `rounded-md/lg/xl`、`text-sm/xs` 类名**自动归位**，不用动 200 多处调用点。

圆角四档（规则：容器越大圆角越大；子元素比父元素小一档）：
| token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | 浮层里的小项（下拉选项）、行内代码、微标签 |
| `--radius-md` | 8px | 按钮 / 输入框 / 下拉触发器 / tab / 导航项 / 窗口按钮 |
| `--radius-lg` | 10px | 卡片内部的块：分段控件容器、滚动区、提示条、搜索框 |
| `--radius-xl` | 14px | 卡片 / 面板 / 独立浮层 / 大块容器 |

刻意保留默认值不走梯度的两档：`rounded-full`（胶囊/圆点）、`rounded`=4px
（≤24px 的微图标按钮、浮层微角标、截图上的框标记）。

字号七档（只留整数）：10 微角标 / 11 次要 / 12 正文 / 13 强调正文·卡片标题·按钮 /
14 强强调 / 16 小节标题 / 26 页面主标题·大数字。

## #76 全面检查与优化：测试 / 文档 / 打包验收

### 修掉的真 bug（两个）

**1. 接口分组错位**（`src/lib/endpoints.ts`）
`groupOf()` 按 `/vision` 前缀把 `/vision/prompt` 划进「看图」，但它在 `ENDPOINTS` 数组里
写在「找图」段、出参也和模板找图同构 → 接口页上它跑到别组，注释和实际分组对不上。
加特判归 `find`（分组变成 找图 8 / 看图 3，总数仍 18）。

**2. 能力不支持被拍成 500**（`src-tauri/src/api/state.rs`，打包验收跑出来的）
`/vision/prompt` 的 `mode=text` 缺 MobileCLIP2-B 权重时返回 **500**，
按 `docs/ENGINES.md` 4.3 应该是 **1002**。根因：`prompt_find` 直接
`ApiError::Internal(format!("提示找图失败: {e}"))`，**绕过了仓库里早就有的
`map_engine_err`**（`Unsupported`→1002、`UnknownEngine`→1003），
而 `/vision/detect` 一直在用它。`run_alt`（拿检测引擎做识别）与 `run_pp` 同样漏了。

修法：拆出 `map_engine_err_ctx(e, Option<&str>)`——code 不变、消息加一层上下文
（`map_engine_err` = `map_engine_err_ctx(e, None)`）；顺带把 `VisionError::BadRequest`
映射成 400（原先也是 500）。三处调用点统一走它。
**为什么必须修**：1002 的全部意义是让脚本区分「引擎做不到，换条路」和「服务故障了」，
都变 500 就没法写自动降级。补 2 条单测钉住（lib 111 → 113）。
