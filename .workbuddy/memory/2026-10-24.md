# 2026-10-24 工作日志

## 表格识别（v0.1.6）

用户否掉 YOLO26n（「才一点点类别，没用」），要「两个表格的」。落成一对配套模型，
共 14.5MB，走模型库按需下载（id=`table`，13.3MB），主包体积不变（50.4MB）。

| 文件 | 模型 | 体积 | 作用 |
|---|---|---|---|
| `models/table/detect.onnx` | PicoDet（PP-DocLayout-S 的 table-only 版） | 7.06MB | 整页找表格 |
| `models/table/structure.onnx` | SLANet-plus | 7.4MB | 表格图 → HTML + 格子框 |

来源（ModelScope，匿名可下、支持 range）：
- `https://www.modelscope.cn/models/RapidAI/RapidTable/resolve/master/slanet-plus.onnx`
- `https://www.modelscope.cn/models/RapidAI/RapidLayout/resolve/master/onnx/pp_layout/layout_table.onnx`

### 三个坑（都花过一次死路）

1. **SLANet 的 pad 填 0，不是 127.5**。paddlex 的 `Pad(val=127.5)` 套上去会输出
   500 个 `colspan` 垃圾 token；PaddleOCR 的 `PaddingTableImage` 才是 zeros。
   顺序也对：resize 长边 488 → **归一化** → pad 成 488×488 → CHW。
2. **bbox 两轴都乘 `max(宽,高)`**。图 pad 成方形，输出坐标相对方形；按「x 乘宽、
   y 乘高」得到压扁的框（实测 y 只有真实值的一半）。
3. **PicoDet 的分数已经是概率，不要再 sigmoid**。再套一层把背景的 0 变成 0.50 →
   detect 返回 **4093 个框** → auto 模式挨个识别 → 六核满载 **3500 CPU 秒**、
   请求永不返回。现象只有「界面一直转圈」，日志里连错误都没有，最难查的一次。

### 排查工具（都留下了）

- `scripts/_probe_slanet.py` / `_probe_layout.py`：Python 原型，参数组合一次试完
  再翻译成 Rust。**先原型后 Rust** 这次省了大量编译等待（每次重编 release 6 分钟）。
- `scripts/_verify_ui/_t_detect.py`：四种组合分别计时（detect/structure/auto ×
  带不带文字），超时 20 秒。第一次用 180 秒超时，整个 PowerShell 工具先被 120 秒
  上限杀掉，什么输出都没有 —— **测卡死一定要设短超时**。
- `scripts/_verify_ui/_clip_image.py`：把 PNG 放进剪贴板（CF_DIB），配合
  `_paste.py` 发 Ctrl+V，用来在没有文件对话框的情况下喂图给界面。
  64 位下必须显式声明 `GlobalAlloc.restype`，否则 HGLOBAL 被截断、memmove 报
  access violation。

### 顺带修的

- **ONNX Runtime 日志转发降级到 ERROR**。SLANet 动态维度每推理一次刷几十条
  shape warning，日志一天长到 **120 万行**，把 INFO 全埋了。改在
  `ort_util::ort_env()` 里 `env.set_log_level(LogLevel::Error)`。
- **缺模型返回 503 而不是 500**。500 是「服务坏了」的语义，会让人去翻日志；
  503 +「去模型库下一个」才对。
- **图上叠加框要贴图片实际显示的矩形**。`object-contain` 会在容器里留白，
  按容器百分比算会整体偏移（第一版框跑到图片外面）。
- `pack_exe.ps1` 里的内嵌说明还写着「三档模型都带了」「提示找图随包带」，
  0.1.5 改按需下载后就错了，一并改掉。

### 已知限制

- SLANet 输出的位置数有限（实测算到 19/32 位置），**单元格太多的表会被截断**，
  已显式返回 `truncated: true`。
- DirectML 上 SLANet 预热失败（Loop/Cast 算子不支持），自动降级 CPU。
  实测 CPU 上单张表格 300~800ms（首次含模型加载更久）。
