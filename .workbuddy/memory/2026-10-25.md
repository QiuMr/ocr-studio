## 环境自检落地 + 验收（2026-10-25 中午续）

新增 `src-tauri/src/envcheck.rs`，四项体检全部接通：

1. **WebView2 检测**：`webview2_version()` → `read_pv(root)`，**HKCU 与 HKLM 都查**。
   - **本机实测：HKCU 没有 `pv`，只有 HKLM 有 `155.0.4283.62`** —— 早期只查 HKCU 的写法
     会在这台机器上把「已装」判成「没装」，每次启动都弹安装引导。**这不是加固，是必修**。
     Win11 出厂预装 / 企业批量部署 / 被别的 Electron 程序带装的，走的都是每机器安装（HKLM）。
   - 路径里写死 `WOW6432Node`：EdgeUpdate 客户端项固定登记在 32 位视图，64 位进程默认视图读不到。
2. **一键安装** `offer_webview2_repair`：原生 `MessageBoxW` 三按钮（立即安装 / 打开官网 / 暂不处理），
   选「是」才下载 bootstrapper 并 `/silent /install`，装完问是否立即重启。**绝不静默动系统组件**。
   - 分支三路：Win7/8 → 系统太旧；没装 → 装；装了但窗口仍建不起来 → 引导更新（版本太老 / GPU 进程崩）。
3. **端口占用**：`GetExtendedTcpTable`（feature `Win32_NetworkManagement_IpHelper`）→ PID →
   `QueryFullProcessImageNameW` 拿进程名。bind 失败 emit `service-error`，前端给「去设置改端口」。
   - **`dwLocalPort` 字节序坑**：文档说「网络字节序」，实际低 16 位是 `{hi,lo}` 顺序存放。
     代码里两种解释都试（`lo == port || lo.swap_bytes() == port`），并写了
     「自己开临时端口 → 回查必须命中自身 PID」的单测钉住 —— 写错字节序这条必红。
4. **DirectML 降级告知**：ServicePage 直接读 `health.actual_device === "cpu" && cfg.device === "directml"`
   渲染可关闭提示条（不需要新事件通道）。
5. **托盘入口**：`tray-status` payload 加 `webview2_missing`，菜单顶部高亮「安装 WebView2」。
   - **反直觉事实**：WebView2 真缺失时，托盘菜单**本身也是个 WebView 窗口**，建不起来 → 那条菜单点不到。
     所以在 `show_tray_menu_inner` 的「菜单窗口创建失败」分支里补了一次 `offer_webview2_repair`
     （`static OFFERED` AtomicBool 保证只补一次，别每次点托盘都弹）。
   - `tray_action` 的 `"webview2"` 分支**必须另起线程**：同步命令跑在主线程，下载+安装几十秒会把界面连同托盘冻住。
6. 安装期间托盘 tooltip 会被 2s 状态循环覆盖 → 加 `INSTALLING` 标志（`InstallingGuard` RAII 复位），
   循环侧读到就跳过写 tooltip。
